# Paint

Eine Web-Anwendung zum Malen direkt im Browser.

Funktionen:

-20 Farben: Wähle aus einer Palette von 20 verschiedenen Farben.

-Pinselgröße anpassen: Passe die Dicke deines Pinsels individuell an.

-Leinwand löschen: Setze dein Bild mit einem Klick zurück.

-Bild speichern: Speichere deine Bilder als Bilddatei auf deinem Gerät.

-Schritte rückgängig/wiederherstellen: Gehe einen Schritt zurück oder wieder vor, um Fehler zu korrigieren oder Änderungen zu testen.


Verwendung:

Öffne die Webseite im Browser.

Wähle eine Farbe aus der Palette.

Passe die Pinselgröße nach Wunsch an.

Male auf der Leinwand.

Verwende die Rückgängig-/Wiederherstellen-Funktion, um Schritte zu korrigieren.

Lösche die Leinwand oder speichere dein Bild, wenn du fertig bist.
